# Python_Hangman_Game

A simple command-line Hangman game built with Python.

The player has 6 lives to guess the letters in a randomly selected word. 
For each correct guess, the letter is revealed in its correct position. 
For each incorrect guess, a life is lost and the Hangman artwork progresses.

## Features

- Randomly selects a word from a word list
- Displays hidden letters using placeholders
- Allows the player to guess letters
- Keeps track of correctly guessed letters
- Prevents previously guessed letters from being counted as new guesses
- Tracks the player's remaining lives
- Displays different Hangman stages based on remaining lives
- Detects win and lose conditions
- Reveals the word when the player loses

## Technologies Used

- Python
- `random` module
- Lists
- Loops
- Conditional statements
- Functions/modules
- String manipulation
- User input
